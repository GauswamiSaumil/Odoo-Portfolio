# Odoo Portfolio

Hi, I'm Saumil Gauswami 👋

A collection of practical Odoo solutions focused on custom frontend development, ERP automation, cross-version migration, and database operations.

This repository also contains a responsive portfolio website that presents the work through interactive project cards and capability sections.

## Featured Projects

### Attachment Previewer

An Odoo 18 web module that extends attachment previews across mail, kanban views, and many-to-many binary fields. Users can inspect files without leaving their current workflow.

**Technologies:** Odoo 18, OWL, JavaScript, XML

### Smart Data Migrator

A Python and XML-RPC migration layer for transferring records between Odoo versions. It preserves external IDs, resolves relational fields, and caches previously processed records.

**Technologies:** Python, XML-RPC, Odoo ORM concepts

### HTML Editor Extender

An Odoo 16 backend extension that brings reusable canned responses into rich-text editing workflows.

**Technologies:** Odoo 16, JavaScript, XML, Web Editor

### Bulk Product Image Sync

An automation script that matches image files or folders with product references and uploads the images to Odoo in batches.

**Technologies:** Python, XML-RPC, Base64

### Database Restore Assistant

A lightweight desktop utility for selecting SQL or dump files and restoring PostgreSQL databases through a simple graphical interface.

**Technologies:** Python, Tkinter, PostgreSQL
